# ARTH design reference

Source: https://www.figma.com/design/ZF94DEQh5FMtmGMPbUMjjT/Finance-App?node-id=0-1

Core tokens: primary #1413FF, secondary #2743FD, success #20C968, text #3A3A3A, muted #B9B9B9, white #FFFFFF. Montserrat is the primary typeface, with Inter and Shanti supporting. Balance card radius 44; reference viewport 375x805.

Frames: welcome 2:4, sign-in 5:46, OTP 6:291, profile 6:394, home 7:559, menu 9:3, transfer 9:43, confirmation 9:83.

Replace MONEY branding with ARTH and localize currency to INR. Preserve original layout where practical. New payment features need their own designs. Original images, illustrations, fonts and exact rendering have not been integrated. The provisional shell is not a faithful implementation yet. Never use a screenshot as the implemented screen.
