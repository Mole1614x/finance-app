# PR 11 — Native UX refinement (partial Figma phase)
The Figma source could not be refreshed: the connected Starter plan returned its MCP call limit. Original asset downloads were previously DNS-blocked. Therefore this PR does not claim a completed Figma implementation or visual parity. No replacement artwork or screenshots are embedded. It refines existing native screens and existing extracted color tokens only.

Shared controls: wrapped labels that grow with content, minimum 48dp action targets, centered scroll panels capped at 560dp, consistent rounded actions and input outlines. Dashboard: compact quick-action grid, more readable balance color, and shared navigation buttons. Onboarding: reduced blank space, local demo input validation and safer in-flight navigation; password and OTP display clearing. Receive: copy the ARTH demo identifier, clear QR on exit. Sign-out is prevented while a dashboard request is in flight. The existing backend behavior and payment confirmation requirements are preserved.

A Linux graphical smoke test constructs all screens and exercises welcome/sign-in/back and button geometry under Xvfb. It is not full end-to-end authentication or payment testing, a screenshot comparison, Android APK build or physical device verification. Exact Figma assets, typography, screen-by-screen parity, device testing and broader UI integration remain open.
