# PR 12 — Optional Gemini and LangGraph explanations
The default assistant is deterministic and works offline. The existing authenticated POST /api/v1/analytics/assistant accepts a fixed topic (spending, budget, savings, risk) and strict boolean allow_external_ai, default false. Existing answer facts are authoritative; optional explanation and fallback_reason fields are additive. A LangGraph routes to a local node or a single Gemini node. No agent tools, payments, write access, free-text conversation, persistent memory, external tracing or autonomous execution.

Enable only for fictional demo data: set ARTH_AI_ENABLED=1, ARTH_GEMINI_API_KEY to your private key, and ARTH_GEMINI_MODEL to a model supported by your Gemini account. For Compose use the private .env and recreate API; for local Uvicorn set environment variables before starting. Do not commit the key. No key is required for default operation. The mobile switch defaults off on each screen entry; the user opts in before selecting a topic. The provider receives only fixed topic, allowlisted service categories and aggregate integer paise, or a count of review flags. No user name, goal title, email, IDs, individual transaction details, tokens or arbitrary user input. Google processes the aggregate data under its own terms. Never use real financial data.

One bounded provider call, no automatic retries, per-peer AI route limit of 10/minute, and local fallback on errors, empty results or absent configuration. Generated text may be inaccurate and is displayed separately from local facts. LangGraph tracing is explicitly disabled for this invocation. The provider is mocked in CI; no actual Google API request, model access or real billing has been verified. This is not a free-text chatbot or validated financial adviser. Exact Figma matching and physical-device tests remain pending.
